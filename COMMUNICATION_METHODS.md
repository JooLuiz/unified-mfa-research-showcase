# Communication Methods Report

This report describes the `main` branch. The method column is the window CustomEvent name, the header element event name, or the iframe `postMessage` type.

## 1. Events

### Shell and remote intents

| Triggering App                                                                                            | Entity        | What Is Communicated                                                       | Method                                            | Affected App(s)                                                                        |
| --------------------------------------------------------------------------------------------------------- | ------------- | -------------------------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Ecommerce Shell (`navigate.js`)                                                                           | Navigation    | A route change occurred and the shell should render again                  | `global:renderApp`                                | Ecommerce Shell (`main.js` calls `renderApp()`)                                        |
| Ecommerce Shell (`main.js` auth guard)                                                                    | Navigation    | A protected route redirected to login and the shell should render again    | `global:renderApp`                                | Ecommerce Shell (`main.js` calls `renderApp()`)                                        |

| Social Media Shell (`mountActions.js`, on header `host:logout`)                                           | Account       | User requested logout                                                      | `auth:logout-request`                             | Social Media Shell (`main.js` clears auth and navigates to `/`)                        |

| Ecommerce Shell (`cartActions.js`, from Product Card, Product Details, or Product Showcase `onAddToCart`) | Cart          | Item to add: `{ productId, quantity }`                                     | `cart:add-item`                                   | Ecommerce Shell (`main.js` adds the item to `appState.cartItems` and re-renders)       |
| Ecommerce Shell (`cartActions.js`, `placeCheckoutOrder.js`)                                               | Cart          | Cart contents were modified (update, remove, or order placed)              | `cart:updateGlobalCart`                           | Ecommerce Shell (`main.js` syncs `window.__APP_SHELL_CART__`)                          |
| Header (`header-element.js`)                                                                              | Navigation    | User clicked a nav link: `{ path }`                                        | `host:navigate` CustomEvent on the header element | Hosting shell (`mountActions.js` calls `navigate(path)`)                               |
| Header (`header-element.js`)                                                                              | Account       | User clicked Log out                                                       | `host:logout` CustomEvent on the header element   | Hosting shell (`mountActions.js` publishes `auth:logout-request`)                      |

`host:navigate` and `host:logout` are events on the header element. The other rows in this subsection are window CustomEvents. Each shell's `browserTransport.js` maps the shared contract names onto `global:renderApp`, `auth:changed`, and `auth:logout-request`. The ecommerce transport also maps cart contracts onto `cart:add-item` and `cart:updateGlobalCart`.
